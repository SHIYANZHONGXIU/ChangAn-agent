# 长安 · 多模型 Agent 工作台

长安是一个使用 Python 与 CustomTkinter 编写的 Windows 桌面助手，围绕本地项目组织聊天和任务，支持模型协作、工具执行、过程记录与任务恢复。

当前默认协作流程：**GPT 分析 → DeepSeek 执行 → Claude 优先核验**。未配置 Claude 密钥，或 Claude 请求不可用时，使用 GPT 核验。各角色的模型与兼容服务地址可在界面中设置。

本项目使用 AI 辅助开发，目前为个人桌面项目。源码位于 [`changan-agent/`](changan-agent/)，完整操作说明见 [使用文档](changan-agent/README.md)。

## 快速开始

需要 Windows 和 Python 3.10 或更新版本，模型调用需要自备服务账号与 API 密钥。

1. 点击仓库上方 **Code → Download ZIP**，下载后解压。
2. 进入解压目录中的 `changan-agent` 文件夹。
3. 首次使用双击 `安装依赖.bat`，完成依赖安装。
4. 双击 `启动桌面版.bat`，在右侧设置 GPT、DeepSeek 的地址、模型和密钥；Claude 可选。
5. 新建项目并选择本地文件夹，然后创建聊天、发送任务。

开发者也可以在源码目录执行：

```powershell
cd changan-agent
python -m pip install -r requirements.txt
python desktop_app.py
```

如果使用虚拟环境，请使用该环境的 Python；一键入口会优先使用源码目录内的 `.venv`。

## 主要功能

| 功能 | 当前能力 |
| --- | --- |
| 多模型协作 | 分析、执行、核验；核验服务故障时降级至 GPT |
| 项目与聊天 | 本地项目目录、搜索、改名、移动、归档和草稿保存 |
| 工具执行 | 项目文件读写、命令执行、网页读取和浏览器基础操作 |
| 文档工具 | PDF/Word 内容提取、Excel 范围读取与单元格修改 |
| 任务恢复 | 分阶段检查点、保存工具结果、继续中断任务 |
| 运行详情 | 模型返回内容、工具事件、网络重试与核验记录 |
| 产物管理 | 文本预览、文件备份、差异查看和恢复 |
| 交互 | 运行计时、明暗主题、代码块复制、跳到最新消息 |
| 任务调度 | 持久化等待队列，单并发执行 |
| 用量与预算 | 输入/输出分别估价、请求前预算检查 |

主对话以最终回答为主；运行详情可显示模型流式返回。部分最终文本使用逐字显示动画，不能将其等同于审核前实时输出最终答案。

## 模型与服务配置

- 当前使用 OpenAI 兼容的 `POST /chat/completions` 接口；Claude 也需要提供这种兼容接口，暂不支持 Anthropic 原生 Messages 协议。
- 模型名称、思考参数支持和实际价格以服务商为准。界面中存在一个模型名称，不代表当前账号有权限或额度。
- 桌面版请在界面保存设置。[`.env.example`](changan-agent/.env.example) 只是命令行环境变量参考，程序不会自动加载 `.env` 文件。
- 长安是本地桌面程序，模型请求仍会向配置的服务发送相关提问、上下文和工具结果。

浏览器工具首次使用前，在对应 Python 环境中安装 Chromium：

```powershell
python -m playwright install chromium
```

## 执行与恢复

DeepSeek 可以根据真实工具结果继续下一步，默认每轮最多 8 个工具步骤，每步最多 20 个动作。模型返回的工具结果不会被当作本地执行证据。

运行前后保存检查点；在核验阶段中断后，可继续核验已有结果。若退出发生在有副作用的工具操作中，恢复时需要确认是否重试，避免重复执行。

任务达到轮次上限仍未通过时，可以增加最大轮次，再点击“恢复中断任务”。停止会清空等待队列；关闭窗口则保留尚未启动的队列。

## 权限与数据

`ask for approve` 对文件写入、命令、Excel 修改和浏览器操作等要求确认；`full access` 减少逐次审批，但仍保留部分路径和危险命令检查。

**这些是应用权限策略，不是操作系统级沙箱。** 命令可以启动其他程序，浏览器检查也不能替代完整网络隔离。建议先在临时项目中使用审批模式。

Windows 密钥使用 DPAPI 保存；聊天、任务记录和产物仍可能包含个人资料。根目录的 `.gitignore` 排除常见配置、聊天、日志、缓存和备份，但不能自动移除已经提交的文件，网页手动上传时仍需检查内容。

费用统计为估算，实际计费以服务商账单为准；单次已发出的请求仍可能使估算超过预算。

## 验证

在 `changan-agent` 源码目录中双击 `运行测试.bat`，或执行：

```powershell
python scripts/run_checks.py
```

2026-11-01，Windows、Python 3.13.5 环境中的源码与独立发布副本均通过 50 项本地回归，无失败、错误或跳过。测试使用临时数据、假模型和本机模拟 HTTP 服务，不调用真实收费模型。

覆盖请求重试与取消、流式异常、核验降级、权限拒绝、任务恢复、存储备份、聊天迁移、队列隔离、真实 Tk 窗口及办公文件读写。相关说明见 [验证文档](changan-agent/docs/verification.md)。

这些结果不代表真实服务始终可用，也不代表所有业务任务都能正确完成。
