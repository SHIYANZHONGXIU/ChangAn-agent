# 长安 Agent 工作台

Windows 本地多模型助手：GPT 分析任务，DeepSeek 逐步使用工具，Claude 优先审核；未填写 Claude 密钥或 Claude 请求不可用时，自动使用 GPT 审核。

现已提供 64 位 Windows 独立桌面版：双击 `ChangAn.exe` 可启动，不需要另装 Python。桌面版源码与便携发布说明见[Windows桌面版使用与验收](docs/Windows桌面版使用与验收.md)；目前为本机验收版，未签名，也未在干净电脑上完成安装验收。源码入口 `启动桌面版.bat` 仍保留。

长期记忆首版与聊天界面更新见 [使用与验收说明](docs/长期记忆与界面首版验收.md)。主界面采用黑白灰布局：用户消息靠右、长安回答靠左；回答支持 Markdown 标题、粗体、列表、行内代码和可复制代码块，原始格式符号不会直接显示。通过顶部“查看→回答字体大小”可选择 13–18 磅，偏好保存在本机；侧栏“设置与模型”按需打开，输入框下方模型名称可直接进入执行模型设置。

自动记忆候选、真实模型接续与LoRA实验见[首轮验收](docs/自动记忆与模型实验验收.md)和[第二轮评测与LoRA v2](docs/长期记忆第二轮评测与LoRA-v2.md)。第二轮使用虚构会话，开发集接续对照已完成，留出真实模型评测因本机预算拦截而不完整；旧运行曾超过自设token上限，价格未知，因此未继续调用API。LoRA v2在固定1.5B模型上完成三种子筛选，但没有超过直接提示基线，适配器未接入日常聊天。LoRA（低秩适配）是为特定基础模型训练的小型附加参数，不是通用长期记忆。

每轮回答上方显示“用时＋箭头＋细分隔线”，区分各轮对话。运行中实时计时；点击可就地展开本轮模型输出、工具与审核记录，也可转到独立窗口查看。过程默认折叠，窗口缩放和聊天切换保留本次打开状态；旧记录缺少用时则不编造数字。明暗主题均已适配。

窗口顶部提供“文件、编辑、查看、帮助”菜单：新建项目与聊天、添加附件、导出聊天、撤销重做、剪切复制粘贴、侧栏与主题切换等。输入框获得焦点时提示立即让开，避免遮挡光标和中文拼音预编辑；粘贴、删除和草稿恢复都按实际内容刷新提示。

可用 `Ctrl+V` 粘贴截图或复制的文件，把文件拖入输入框，或点击“＋ 附件”选择。发送前显示图片缩略图、文件名和大小，支持移除；附件保存在当前聊天的 `attachments/`，随聊天改名或移动。每次最多8个、单个20 MB，可只发送附件。图片交给 GPT 分析，要求端点支持 OpenAI 兼容图片内容格式；DeepSeek 根据 GPT 提取的图片细节执行。文本、PDF（前20页）、DOCX、XLSX 内容按长度限制提取后提供给分析、执行和核验；其他类型明确标注不能读取。详见 [输入框、菜单与附件说明](docs/输入框菜单与附件说明.md)。

本轮优化内容、50 项本地回归及实际窗口验收见 [优化与验收记录](docs/2026-10-30-优化与验收.md)。

## 使用

1. 首次使用安装 Python 3.10 或更新版本，并双击 `安装依赖.bat`。
2. 双击 `启动桌面版.bat`。启动入口以自身文件夹为基准，不依赖当前工作目录；同一数据目录只允许一个实例。
3. 点击左下角“设置与模型”，配置 GPT、DeepSeek 的 API 地址、模型、密钥。Claude 为可选；当前支持中转站的 OpenAI 兼容 `POST /chat/completions`，不支持 Anthropic 原生 Messages 协议。
4. 新建项目时选择本地文件夹。发送任务后，主对话只显示回答，代码可从代码块复制；目标、工具、审核、网络重试进入“运行详情”。
5. 运行中可继续提交请求，按单并发队列执行。停止会清空等待队列；关闭软件会保存尚未启动的队列，重新打开后通过“恢复中断任务”继续。

Claude 故障后，本次任务后续审核持续使用 GPT，避免反复请求已失效的账户。主动停止、预算超限和程序内部错误不会被误当成 Claude 故障降级。审核通过与否仍会在消息状态中显示。

模型列表只显示对应服务的模型，并保留用户已经选中的模型；服务暂时不可用时，不会自动替换模型。思考参数被服务拒绝时会尝试移除该参数重试。

“设置与模型→运行”新增单次输出上限（默认4096 token）和价格/预算币种（CNY、USD）。价格由用户填写，任一实际使用的模型缺少输入价、输出价或币种时，回答显示“费用未知”；未使用的Claude不会影响汇总。0或留空表示未配置价格，不表示免费。启用金额预算需补齐所有已配置模型的两项价格，并使用同一币种。

每次请求、重试、审核降级和自动提取前会预留输入与最大输出费用。请求前后保存逐次用量记录；取消、断线或崩溃后无法确认计费的请求保留估算，不会因恢复或移除Claude配置而清零。服务返回有效token时按本次价格结算，修改价格不会重算之前的记录。旧任务若没有完整价格/币种记录，不能直接沿用金额预算，需核实历史用量或关闭该任务的本机金额预算。

预留基于本机估计和用户价格，无法保证服务商账单绝不超额；图片、服务商隐含上下文或不遵守输出上限均可能使实际用量不同。建议同时设置服务商账户限额。新规则见[费用与预算验收说明](docs/商业化首批-费用与预算验收.md)。

## 聊天与文件

每个聊天独立保存，可搜索、重命名、归档、恢复和移动到其他项目。聊天与运行数据统一保存在长安的 `data/` 内；详细位置见 [文件夹说明](docs/文件夹说明.md)。

```text
Agent/
  启动桌面版.bat          Windows 启动入口
  安装依赖.bat            首次安装依赖
  运行测试.bat            本地测试，不调用真实模型
  打开诊断日志.bat        打开 data/logs
  *.py                    应用源码，保留现有启动方式
  data/                   本机数据，请勿公开上传
    config/               本机加密配置与上一版备份
    memory/               长期记忆数据库
    logs/                 脱敏诊断日志
    workspace.json        项目、聊天和等待队列索引
    migrations/           旧数据迁移记录
    projects/<项目编号>/
      project.json        项目名称与绑定目录
      workspace/          未绑定外部文件夹时的实际工作文件
      chats/<创建时间-聊天编号-名称>/
        chat.json         完整消息与草稿
        chat.json.bak     上一版聊天备份
        attachments/      主动粘贴或添加的附件快照
        runs/<时间-运行编号>/
          run.json        状态、模型、运行时间与所属聊天
          checkpoint.json 中断恢复进度
          result.json     完整执行与审核结果
          events.jsonl    模型输出及工具过程
          artifacts/
            reports/      回答、报告、说明
            code/         代码留存副本
            data/         JSON、CSV 等数据留存副本
            documents/    PDF、Word、Excel 等文档副本
            images/       图片、浏览器截图
            other/        其他文件
            index.json    副本来源、时间和 SHA-256 校验值
      history/            旧产物、未索引聊天与历史任务
  tests/                  临时数据与模拟接口测试
  scripts/                验证与可选 API 检查
  docs/                   使用与开发说明
  outputs/                测试结果、发布材料和整理报告
  archive/                历史版本与可恢复备份
```

选择本地项目文件夹后，代码与工作文件继续在所选文件夹中修改；文件写入、Excel 修改、浏览器截图和下载产生的留存副本按类型保存到当前聊天、当前运行的 `artifacts/`。同一路径的不同内容使用不同哈希文件名，不覆盖之前的副本。命令任意生成的文件仍在实际工作区，不自动扫描或复制整个项目；其输出和执行状态保存在运行记录中。

点击聊天右上角“文件”可预览产物，并打开本聊天文件夹。重命名或移动聊天会一起移动运行记录与产物，更新对应路径；运行中的聊天需先停止。普通归档仅改变列表状态，不删除数据。移除列表中的项目也不会删除其本地数据。

旧数据首次启动会先复制、校验并更新索引，发生冲突时停止且保留两份。整理前版本仍在 `archive/`。未索引旧聊天不重新加入列表，单独保存在 `history/unindexed-chats/`；没有明确聊天归属的任务存入 `history/runs/`，仍可通过恢复入口选择。

JSON 使用临时文件、刷盘与原子替换，保留上一版；损坏时保留原文件并尝试备份恢复。不要手动删除 `data/`、`.bak` 或索引文件来解决显示问题。外部项目的修改前版本仍在项目本身的 `.agent-backups/`，便于对实际工作文件比较和恢复。

## 长期记忆与自动候选

点击用户消息旁的“记为记忆”，检查内容、填写标题，选择当前项目或通用范围后确认保存；也可以从左下角“记忆”手动新建。支持事实、偏好、项目状态三类，可搜索、查看来源、编辑和删除。无需额外安装依赖。

记录保存在 `data/memory/memory.sqlite3`，支持重启和新聊天。分析、执行与核验会读取同一组有效记忆，最多6条、正文合计5000字符；中文关键词检索可能漏掉同义表达。全局偏好可用于所有项目，项目记忆按稳定项目编号隔离，移动聊天不会搬走来源项目的记忆。

设置的“运行”页可以独立控制记忆使用和“自动整理待确认记忆”。自动提取默认关闭；开启后成功回答会额外调用当前GPT，只处理本轮用户文字，候选在“记忆→待确认”查看，确认后才生效。同名更新展示原内容并确认替换，忽略或删除后不会因恢复同一消息而反复提取；移动聊天会清除其未确认候选。不扫描私人历史或附件，也不自动训练真实聊天。

“删除”只停止使用这条记忆；“彻底忘记来源聊天”会在二次确认后删除整个来源聊天的消息、附件、运行记录、检查点、产物、聊天备份，以及该聊天产生的记忆、候选和提取指纹。它不可恢复，但不删除外部项目实际代码、已经导出的副本或服务商已收到的请求；这些范围需要单独处理。记忆内容和模型输出一样，可能通过请求发送到配置的服务。

新增源码：`long_term_memory.py`、`memory_panel.py`；虚拟连续会话：`tests/fixtures/memory_sessions.json`。数据库及其附属文件已加入忽略规则，发布时仍应检查打包清单；记忆库是本地 SQLite 文件，未加密，不适合存储密钥。

真实模型评测入口为“运行记忆接续评测.bat”（产生API用量）；LoRA为可选独立环境中的“运行LoRA实验.bat”。源码与虚构协议在 `experiments/`，结果、适配器和失败记录在 `outputs/experiments/`。默认桌面启动不加载训练依赖或适配器。

离线记忆压力验收可运行 `python experiments/memory/stress.py --seeds 7,23,41 --snapshots 100`，不产生API消费。LoRA多种子结果可用 `python experiments/lora/aggregate.py <结果目录...>` 汇总；协议、数据或代码不一致时会拒绝比较，未通过通用能力门槛时会给出不继续研究的结论；汇总工具不加载适配器，也不改变桌面配置。

最近一次3种子筛选及存储压力结果见 [本轮验收](docs/长会话压力与多种子验收.md)：格式均值 `0.889`，基础问答均值 `0.250`，因此适配器仍保持停用。

## 执行、恢复与权限

DeepSeek 支持多步工具调用：先读取项目，再根据工具真实结果继续，单轮默认最多 8 步，单步最多 20 个操作。最近 12 条用户/助手消息会作为有长度限制的上下文传入，运行内部过程不会当作用户指令。

- 每次模型请求前、工具执行前后、审核前后均保存检查点。
- 审核阶段中断后恢复，直接审核已有工具结果，不重新执行已完成的命令。
- 达到最大轮次仍未通过的任务，可增加最大轮次后从“恢复中断任务”继续，保留前面各轮的结果和审核意见。
- 如果在修改文件或命令执行期间崩溃，结果未确认，恢复时即使是 full access 也需要确认是否重试，避免重复副作用。
- 最终结果先写入磁盘，再播放界面文字动画。退出不会只保存半句回答；下次启动可找回已经写入的最终结果。
- 模型请求、网页/浏览器请求和命令使用可终止的子进程；网络重试等待也支持取消。文件复制、办公文档解析等短操作仍可能要等待本次操作返回。

`ask for approve` 对命令、文件写入、Excel 修改和浏览器操作逐次确认。没有审批通道时拒绝有副作用的操作，不默认放行。`full access` 可直接执行项目工具，但仍拦截常见磁盘覆写、递归删除、关机重启、分区和注册表修改命令，以及文件工具的越界路径。命令输出最多保留标准输出 20 KB、错误输出 10 KB，超出部分截断；Windows 下每个命令使用关闭即清理的进程组，最多 64 个进程。其他系统会清理同一进程组，但不提供相同的进程数限制。**这两档是应用权限策略，不是操作系统沙箱**；没有 CPU/内存配额，也无法靠有限危险命令规则阻止所有风险。

文件工具阻止访问内部聊天、Git、版本目录与本机配置。HTTP 网页工具连接已验证的公网 IP，并逐次校验重定向。浏览器强制经本地代理连接，每个目标地址在解析后固定连接到已校验的公网 IP；浏览器的直连 DNS 被禁用，且每次最多执行 20 个受支持操作、最多 64 个并发代理连接、单连接 100 MB、单次自动化总流量 200 MB，并继续执行域名和路由检查、禁用 Service Worker。该限制降低 DNS 重绑定和内网请求风险，但仍不是系统级网络沙箱，敏感环境不应对不可信网页开放 full access。

浏览器首次使用需要另行安装 Chromium：

```powershell
python -m playwright install chromium
```

PDF、Word 为内容提取；PDF 每次最多读取 20 页；Office 文档压缩包有大小和展开体积上限；Excel 支持限定范围读取，单次最多写入 10000 个单元格并检查工作表边界。代码、JSON/JSONL、CSV、PDF、Word、Excel 等已写产物会做对应的基础结构检查。界面可预览文本，二进制文件需要系统关联软件。语法、结构校验与工具返回码仍不代表业务逻辑或外部事实已经被证明正确。

## 验证与诊断

双击 `运行测试.bat`，或运行：

```powershell
python scripts/run_checks.py
```

会启动使用临时配置和假模型的真实 Tk 窗口，验证消息显示、代码块、草稿、跨聊天隔离与安全关闭；其余测试使用本机模拟接口与临时目录，覆盖重试、取消、截断流、权限、备份和恢复。不会发送真实模型请求。报告保存到 `outputs/verification/<日期>/`。

日志位于 `data/logs/changan.log`，错误中的常见密钥格式会被隐藏；模型执行内容和工具结果保存在项目本地运行记录中，仍可能包含任务资料，分享前需要检查。Windows DPAPI 密钥仅限原 Windows 用户解密，无法解密时会保留原密文并要求重新填写。

可选执行 `python scripts/api_smoke_test.py` 只读取真实模型列表。没有实际聊天请求成功，不能据此断言模型已可用。

需要隔离测试或使用另一份数据目录时，可设置 `CHANGAN_DATA_DIR`，其值是数据根目录（内部包含 config、memory、projects 等子目录）。设置 `CHANGAN_OFFLINE=1` 仅关闭启动时自动拉取模型列表，不会把模型变为离线模型。

## 当前边界

这是可在本机验证的桌面 Agent，尚未提供签名安装包、操作系统级沙箱、多用户共享或完整浏览器/办公软件编辑器。模型回答仍可能出错；服务商额度、模型别名与收费情况取决于实际端点。源码快照和本次验收记录分别保存在 `archive/` 与 `outputs/verification/`，更新前请保留运行数据。
