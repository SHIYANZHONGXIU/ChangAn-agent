# 长安 Agent 工作台

Windows 本地多模型助手：GPT 分析任务，DeepSeek 逐步使用工具，Claude 优先审核；未填写 Claude 密钥或 Claude 请求不可用时，自动使用 GPT 审核。

2026-10-30 本地验收记录见 [验证说明](docs/verification.md)。本项目使用 AI 辅助开发。

## 使用

1. 首次使用安装 Python 3.10 或更新版本，并双击 `安装依赖.bat`。
2. 双击 `启动桌面版.bat`。启动入口以自身文件夹为基准，不依赖当前工作目录；同一数据目录只允许一个实例。
3. 在右侧设置 GPT、DeepSeek 的 API 地址、模型、密钥。Claude 为可选；当前支持中转站的 OpenAI 兼容 `POST /chat/completions`，不支持 Anthropic 原生 Messages 协议。
4. 新建项目时选择本地文件夹。发送任务后，主对话只显示回答，代码可从代码块复制；目标、工具、审核、网络重试进入“运行详情”。
5. 运行中可继续提交请求，按单并发队列执行。停止会清空等待队列；关闭软件会保存尚未启动的队列，重新打开后通过“恢复中断任务”继续。

Claude 故障后，本次任务后续审核持续使用 GPT，避免反复请求已失效的账户。主动停止、预算超限和程序内部错误不会被误当成 Claude 故障降级。审核通过与否仍会在消息状态中显示。

模型列表只显示对应服务的模型，并保留用户已经选中的模型；服务暂时不可用时，不会自动替换模型。思考参数被服务拒绝时会尝试移除该参数重试。价格由用户配置，统计为估算值，不能替代服务商账单；未返回 token 时会标明估算。预算在每次请求和重试前检查，一次已发出的请求仍可能使估算超过上限。

## 聊天与文件

每个聊天独立保存，可搜索、重命名、归档、恢复、移动到其他项目。切换聊天会保留未发送草稿。长聊天先显示最近 60 条消息，可加载更早内容。

```text
Agent/
  启动桌面版.bat        Windows 启动入口
  安装依赖.bat          安装依赖
  运行测试.bat          本地测试，不调用真实模型
  打开诊断日志.bat      打开日志目录
  desktop_app.py        桌面界面与任务调度
  orchestrator.py       模型请求、工具与闭环执行
  persistence.py        原子写入、备份、聊天存储与迁移
  app_runtime.py        单实例锁、脱敏日志与运行事件记录
  network_safety.py     外部网页地址检查与固定地址连接
  message_format.py     保持代码原始缩进的代码块识别
  specialized_tools.py  浏览器、PDF、Word、Excel 工具
  validators.py         Python、JSON、CSV 基础校验
  secret_store.py       Windows DPAPI 密钥保护
  tests/                模拟接口、恢复与实际 Tk 窗口回归
  scripts/              验证与可选 API 检查
  docs/                 说明与截图
  archive/              改动前源码快照
  outputs/verification/ 验证记录
  logs/                 脱敏诊断日志（滚动保留）
  agent_config.json     本机加密配置
  workspace.json        项目和聊天索引，不内联全部消息
```

用户选择的项目目录内：

```text
项目目录/
  .changan/chats/创建时间-聊天编号-聊天名称/
    chat.json
    chat.json.bak
    runs/运行编号/
      run.json           项目、聊天、状态、累计运行时间
      checkpoint.json    当前阶段与每个已完成工具的结果
      result.json        完整执行与审核结果
      answer.md          最终回答
      events.jsonl       运行事件与模型输出（本地）
  .agent-backups/         修改前版本与索引
```

未绑定本地文件夹的旧项目使用 `Agent/projects/<项目编号>/`。旧版项目根目录 `runs/` 检查点仍可恢复。重命名和移动使用实际目录迁移，保留聊天目录中的附属文件；运行中的聊天需停止后再迁移。文件版本按完整相对路径匹配，恢复前再次备份当前内容。

JSON 保存使用临时文件、刷盘与原子替换，保留上一个版本；损坏时保留原文件并尝试备份恢复。不要手动删除 `.bak`、`.changan` 或 `workspace.json` 来解决显示问题。

## 执行、恢复与权限

DeepSeek 支持多步工具调用：先读取项目，再根据工具真实结果继续，单轮默认最多 8 步，单步最多 20 个操作。最近 12 条用户/助手消息会作为有长度限制的上下文传入，运行内部过程不会当作用户指令。

- 每次模型请求前、工具执行前后、审核前后均保存检查点。
- 审核阶段中断后恢复，直接审核已有工具结果，不重新执行已完成的命令。
- 达到最大轮次仍未通过的任务，可增加最大轮次后从“恢复中断任务”继续，保留前面各轮的结果和审核意见。
- 如果在修改文件或命令执行期间崩溃，结果未确认，恢复时即使是 full access 也需要确认是否重试，避免重复副作用。
- 最终结果先写入磁盘，再播放界面文字动画。退出不会只保存半句回答；下次启动可找回已经写入的最终结果。
- 模型请求、网页/浏览器请求和命令使用可终止的子进程；网络重试等待也支持取消。文件复制、办公文档解析等短操作仍可能要等待本次操作返回。

`ask for approve` 对命令、文件写入、Excel 修改和浏览器操作逐次确认。没有审批通道时拒绝有副作用的操作，不默认放行。`full access` 可直接执行项目工具，但仍拦截部分危险命令和文件工具的越界路径。**这两档是应用权限策略，不是操作系统沙箱**；命令可以启动其他程序，无法靠有限规则阻止一切危险行为。

文件工具阻止访问内部聊天、Git、版本目录与本机配置。HTTP 网页工具连接已验证的公网 IP，并逐次校验重定向。浏览器做域名、公网地址和请求路由检查，禁止 Service Worker；其网络隔离仍不等同于专门沙箱，敏感环境不应对不可信网页开放 full access。

浏览器首次使用需要另行安装 Chromium：

```powershell
python -m playwright install chromium
```

PDF、Word 为内容提取；Excel 支持限定范围读取和单元格写入。界面可预览文本，二进制文件需要系统关联软件。Python 语法、JSON、CSV 校验与工具返回码属于基础机器校验，不代表业务逻辑或外部事实已经被证明正确。

## 验证与诊断

双击 `运行测试.bat`，或运行：

```powershell
python scripts/run_checks.py
```

会启动使用临时配置和假模型的真实 Tk 窗口，验证消息显示、代码块、草稿、跨聊天隔离与安全关闭；其余测试使用本机模拟接口与临时目录，覆盖重试、取消、截断流、权限、备份和恢复。不会发送真实模型请求。报告保存到 `outputs/verification/<日期>/`。

日志位于 `logs/changan.log`，错误中的常见密钥格式会被隐藏；模型执行内容和工具结果保存在项目本地运行记录中，仍可能包含任务资料，分享前需要检查。Windows DPAPI 密钥仅限原 Windows 用户解密，无法解密时会保留原密文并要求重新填写。

可选执行 `python scripts/api_smoke_test.py` 只读取真实模型列表。没有实际聊天请求成功，不能据此断言模型已可用。

需要隔离测试或使用另一份数据目录时，可设置 `CHANGAN_DATA_DIR`。设置 `CHANGAN_OFFLINE=1` 仅关闭启动时自动拉取模型列表，不会把模型变为离线模型。

## 当前边界

这是可在本机验证的桌面 Agent，尚未提供签名安装包、操作系统级沙箱、多用户共享或完整浏览器/办公软件编辑器。模型回答仍可能出错；服务商额度、模型别名与收费情况取决于实际端点。源码快照和本次验收记录分别保存在 `archive/` 与 `outputs/verification/`，更新前请保留运行数据。
