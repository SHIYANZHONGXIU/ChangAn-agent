# 长安长期记忆第二轮评测与 LoRA v2

日期：2026-11-02。全部评测资料均为人工构造的虚构会话；未导入个人聊天、私人记忆或密钥。

## 结论先看

- 已建立并冻结30组长会话与同组划分的本地偏好评测集：训练12组、开发8组、留出测试10组。
- GPT 与 DeepSeek 的真实接续评测完成了开发集，但留出测试只运行一部分。旧版用量检查未在单次请求前预留 token，实际累计515,475 token，超过本机冻结的500,000 token上限15,475。没有继续发真实请求；实际费用未知。
- 本地0.5B基线未达到训练门槛。之后改用固定版本的1.5B候选模型，在开发集通过训练门槛，按三个随机种子完成 LoRA v2 筛选。
- LoRA v2 没有超过直接提示/外部偏好基线，三种子结果一致，因此**不继续扩大、不接入日常长安、不启用适配器**。
- 已修复接续评测脚本的单次请求预留和未发送题目统计，并加回归测试。修复后没有再调用真实 API。

## 1. 新评测数据

`experiments/round2/memory_sessions.json` 与 `lora_data.json` 都由固定种子生成，哈希冻结在 `experiments/round2/protocol.json`。30组完整会话按组划分，防止同一组进入训练与测试。问题覆盖更新后的事实、当前要求覆盖偏好、未知信息、项目隔离、已删除来源、未来信息、简单算术等场景。预期答案只用于离线打分，不会传给待测模型。

数据规模是可控的合成筛选集，不等同真实用户聊天分布，也不能代替正式研究中的独立、多来源语料。

## 2. 真实 GPT / DeepSeek 长会话接续

评测比较近期消息、完整历史、滚动摘要和外部记忆；虚构资料经 GPT 提取后，再由 DeepSeek 在新请求中读取，并额外测试删除后的回答。报告保留每次请求、输出、用量和本地 SQLite 快照。

| 开发集条件 | GPT | DeepSeek |
|---|---:|---:|
| 仅近期消息 | 10/18（55.6%） | 10/18（55.6%） |
| 完整历史 | 17/18（94.4%） | 18/18（100%） |
| 滚动摘要 | 17/18（94.4%） | 17/18（94.4%） |
| 外部记忆 | 16/18（88.9%） | 18/18（100%） |

开发集只有两组会话。完整历史、摘要、外部记忆都明显优于仅近期消息，但样本太小，无法证明三者之间的质量或成本优劣。真实提取、切换模型、重新读取以及删除后再问的虚构端到端样例通过；这不是完整真实长会话评测。

留出测试中只有11条回答请求完成，其余69条回答请求（621道题）及16条摘要请求被本机预算挡下。原始汇总把“未发送”误算为模型错误。已保留原报告，并在 `outputs/experiments/2026-11-02_115303-round2-memory/report-corrected.json` 和 `报告-复核.md` 单独生成修正后的派生统计：未发送题不进入已尝试准确率分母，发送后失败仍计为失败。原始报告没有覆盖。

旧运行统计515,475 token，超过本机设定的500,000上限15,475。价格未配置，服务商实际账单未知；token用量不是费用账单。为避免额外消费，本次没有继续请求。新代码会按请求字节、输出上限及预留空间在发送前挡住超预算请求，并能识别未发送项；相关测试已加入。

## 3. LoRA v2 本地基线与三种子评估

固定模型为 `Qwen/Qwen2.5-1.5B-Instruct`，revision `989aa7980e4cf806f80c7fef2b1adb7bc71aa306`。它与此前0.5B实验分开记录，不能将两者数值混作同一协议。0.5B开发基线的格式得分为0、一般题为0.375，故当时正确停止了训练；1.5B候选通过协议中的开发门槛后才启动LoRA v2。

| 开发集条件（8组） | 格式通过率 | 一般题正确率 | 当前要求覆盖偏好 |
|---|---:|---:|---:|
| 1.5B基础模型 | 0/8 | 15/16（93.8%） | 7/8（87.5%） |
| 直接提示 | 7/8（87.5%） | 16/16 | 16/16 |
| 外部偏好 | 7/8（87.5%） | 16/16 | 16/16 |

该结果通过了训练放行门槛。LoRA v2 使用100步、学习率 `5e-5`、秩8、alpha16、梯度累积4、最大训练长度640；包含直接偏好与外部偏好训练上下文。分别使用42、1337、2026三个种子，固定最后一步，不按测试集挑选检查点。训练及测试在 RTX 4080 上完成。每个结果都验证了保存后重载一致、停用适配器后回到基础输出一致。

| 测试集条件（10组） | 格式通过率 | 一般题正确率 | 当前要求覆盖偏好 |
|---|---:|---:|---:|
| 基础模型 | 0/10 | 20/20 | 9/10（90%） |
| 直接提示 | 10/10 | 20/20 | 10/10 |
| 外部偏好 | 10/10 | 19/20（95%） | 4/10（40%） |
| 仅 LoRA | 0/10 | 20/20 | 10/10 |
| 外部偏好＋LoRA | 10/10 | 19/20（95%） | 10/10 |

三种子的上述比例完全相同（均值标准差为0）。`style`是格式评分，不代表建议内容正确；当前内容覆盖指标要求回答中逐字包含所有预设要点，而本轮覆盖率为0，因此不能宣称回答内容质量已验证。外部偏好单独使用时，测试集格式达标但“当前明确格式优先”表现只有40%；LoRA没有修复这个问题。

多种子汇总显示：直接提示和外部偏好已达到10/10格式，LoRA自身为0/10，组合方案也只是与外部偏好基线持平，没有达到预设的格式收益；一般能力、保存重载和回滚门槛通过，但总体研究门槛未通过。因此保留实验适配器和报告用于审查，不将其接入应用。
