# 长安 Windows 桌面版：使用与验收

长安现已可打包为 64 位 Windows 独立桌面程序。双击 `ChangAn.exe` 打开原有桌面界面，无需在用户电脑安装 Python；无需依赖终端启动。它沿用现有多模型设置、项目与聊天、运行详情、归档、文件附件、长期记忆、审批、恢复和主题功能，不是重写版或 Codex 官方产品。

## 运行与数据位置

保持 `ChangAn.exe` 和同级的 `_internal` 文件夹完整配套。可将整个“长安桌面版”文件夹放在固定位置后双击程序，也可运行 ZIP 中的 `Install-ChangAn.bat`，安装到当前 Windows 用户目录并创建桌面和开始菜单快捷方式，不需管理员权限。源码版入口 `启动桌面版.bat` 保留不变。

新安装默认将密钥配置、聊天、记忆、日志和项目索引保存在 `%LOCALAPPDATA%\ChangAn\data`，与程序分离。若直接把便携程序放在已有长安项目目录中，程序会识别并使用现有数据目录，不会自行复制或迁移。源码版与桌面版共用目录时也共用同一进程锁，不能同时运行。

安装时可选择导入旧长安 `data` 文件夹；安装程序检查旧应用的运行锁并在复制期间持有它，若旧程序仍在运行、没有运行锁，或新数据目录已有文件，则拒绝自动合并。迁移保留原目录并逐文件校验副本；复制失败会保留旧数据。旧 API 密钥仅能在同一个 Windows 用户账户中解密。在开始菜单“长安”文件夹中运行“卸载长安”，可移除程序和安装器创建的快捷方式；用户数据 `%LOCALAPPDATA%\ChangAn\data` 不会被删除。便携版可退出后直接删除程序文件夹。当前提供免管理员用户级安装脚本，不生成 MSI，也没有自动更新。

## 功能与已知限制

- GPT、DeepSeek、Claude 的地址、模型、思考强度、预算和密钥仍由长安设置页管理；打包物不包含本机设置文件或密钥。
- 文本、PDF、Word、Excel 工具随程序打包；文件拖放与图片粘贴依赖程序所带的 Tk 拖放组件和 Pillow。
- 浏览器自动化代码随程序打包，优先使用已有 Playwright Chromium；若没有该内核，Windows 版尝试调用系统自带 Microsoft Edge。浏览器流量强制通过长安本地代理，每次 DNS 解析后固定连接已验证的公网 IP，禁用浏览器直连 DNS，避免校验与实际连接之间被 DNS 重绑定切换地址。单次最多 20 个浏览器动作、64 个并发代理连接、单连接 100 MB、单次自动化总流量 200 MB；下载保存上限 100 MB。当前电脑没有 Edge 时，浏览器自动化不可用，其他聊天和本地工具不受影响。应用代理仍不等于操作系统防火墙或隔离虚拟机。
- 命令输出受限为标准输出 20 KB、错误输出 10 KB。Windows 命令通过 Job Object 限制为最多 64 个进程，并在命令结束、取消或超时时清理该命令的进程树；无法创建进程组保护时拒绝运行。该保护不是 CPU/内存限额，不会阻止所有危险命令，也不覆盖用户在 Agent 外手动启动的程序。
- PDF、DOCX、XLSX 输入文件上限 100 MB；Office 压缩文件限制展开体积、文件数和压缩比；PDF 每次最多提取 20 页。Excel 单次写入最多 10000 个单元格并校验工作表范围。写入后的 Python、JSON/JSONL、CSV、PDF、DOCX、XLSX 会尝试进行语法或结构校验；通过不代表业务结果正确。
- 未对二进制签名。首次下载可能显示 SmartScreen；这不等同于安全审计或数字签名。
- 未在两台干净 Windows 电脑上验收升级与卸载；本机运行验证不替代外部环境测试。二进制未签名，也没有自动更新。

## 本机打包与验收

在本项目的 64 位 Windows 环境执行：

```powershell
python scripts/build_windows_app.py
```

构建会将可执行文件与 `_internal` 运行时放在 `outputs\release\时间戳-windows-x64\长安桌面版\`，并生成可复制的 ZIP、文件 SHA-256 清单、构建日志和实际窗口截图。桌面启动测试通过单独临时数据目录并关闭联网模型刷新执行；不会读取或修改已有密钥、聊天和记忆。

源码修改后的完整本地回归：

```powershell
python scripts/run_checks.py
```
