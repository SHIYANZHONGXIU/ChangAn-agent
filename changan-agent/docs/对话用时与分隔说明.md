# 对话用时与分隔

已按照用户提供的截图，把“用时＋箭头＋细分隔线”接入每轮助手回答的上方。例如“用时 29 分钟 51 秒 ›”。线条与回答同宽，配合左右消息布局区分每轮内容。

运行时显示“正在工作”及实时累计用时；结束后显示实际记录的用时，支持秒、分钟和小时。失败、停止、中断和未通过审核会保留对应提示。旧消息没有时间时仅显示“查看运行过程”，不生成虚假的历史用时。

点击用时条，当前回答上方会展开本轮运行记录：目标、模型输出、工具操作、核验结果等已有内容。再次点击收起。展开区域可选择复制文字，有独立滚动条，也可点击“在独立窗口查看”。同一聊天的多轮过程分别展开，运行中的新内容会刷新到对应轮次，上翻阅读时不强制滚到底部。

窗口缩放、重新渲染或切换聊天后，本次会话的展开状态保留；重启后默认收起。用时和记录沿用原有聊天数据保存，不改变用户消息、回答和产物文件。

本地验收覆盖两轮记录隔离、默认收起、点击展开收起、运行计时、实时追加、聊天切换、重新排版和磁盘记录读取。真实 Tk 临时窗口截图位于 `outputs/verification/2026-11-02/turn-divider/`，包含明暗主题、展开与收起四种状态；截图使用虚拟资料，没有读取真实配置或请求模型。

显示的是服务实际返回并由应用记录的过程，不保证服务提供未返回的思考内容。旧版未记录的耗时和过程无法补回；本次未调用收费 API。
