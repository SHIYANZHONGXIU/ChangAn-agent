# 输入框、菜单与附件

重启长安后生效。当前 Python 环境已安装 Pillow 和 tkinterdnd2；其他电脑首次使用时，请双击“安装依赖.bat”，启动脚本会检查这些必要依赖。

## 输入体验

输入框未聚焦且确实为空时显示提示。点击或用键盘进入输入框，提示立即隐藏；中文拼音还没确认、尚未产生正式文字时也保持隐藏。提示不写入正文，不会被复制、发送或保存成草稿。

移除了内外两层不一致的14像素留白，实际文字、光标和提示使用同一起始区域。通过文字修改事件更新状态，覆盖粘贴、删除、程序写入和恢复草稿；空格和换行也按真实内容处理。切换聊天会清空上一聊天的撤销记录，避免撤销时恢复其他聊天的草稿。

## 顶部菜单

| 菜单 | 已接入功能 |
| --- | --- |
| 文件 | 新建聊天、添加本地项目、添加附件、导出Markdown、打开聊天文件夹、恢复任务、设置、退出 |
| 编辑 | 撤销、重做、剪切、复制、粘贴、全选；输入框也可右键打开 |
| 查看 | 侧栏显示、明暗主题、最新消息、运行详情、聊天产物、记忆、归档列表 |
| 帮助 | 使用说明、目录说明、诊断日志、快捷键、关于长安 |

窗口采用 Windows 原生顶部菜单栏，位于标题栏下方；菜单外观跟随系统绘制，应用正文继续使用自身明暗主题。

快捷键：Ctrl+N新建聊天，Ctrl+Shift+N添加项目，Ctrl+B切换侧栏，Ctrl+O添加附件，Ctrl+,打开设置；Ctrl+V粘贴，Enter发送，Shift+Enter换行。编辑操作面向当前聚焦的文本框；发送或切换聊天会重置输入框撤销栈。

## 添加图片与文件

- 截图后按Ctrl+V，或复制图片后粘贴；剪贴板中是普通文字时保留正常文字粘贴行为。
- 在资源管理器复制文件后Ctrl+V，或拖入输入框；也可点击“＋ 附件”或“文件→添加附件”。文件夹暂不支持整目录添加。
- 发送前显示可横向滚动的附件卡片，包含图片缩略图、文件名、大小与移除按钮。每次最多8个，单个不超过20 MB，大图会在发送前缩小至最长边1600像素。
- 可以只发附件，默认提问为“请分析这些附件”。附件快照在添加时写入当前聊天专属的 `attachments/`，不修改原文件；源文件之后变化不会改写已添加的版本。已发出的附件可从用户消息中的按钮打开。
- 未发送附件随各聊天草稿保存，切换聊天可找回；发送后保留引用，排队和重启恢复从对应任务读取。同一聊天后续继续提问时，若没有新附件，会参考最近12条消息里最近一次附件，避免“继续分析”丢失资料。
- 点击×会从待发送列表中移除，不发送此附件；本轮实现不自动清理聊天目录里已经保存的附件快照，整体删除需另行管理。脚本、程序、快捷方式附件点击时打开其所在文件夹，避免直接运行附件。

## 模型实际会收到什么

图片通过OpenAI兼容的 `image_url` 内容交给GPT；GPT把与任务相关的可见细节整理到目标清单，供DeepSeek执行。若中转端点或所选GPT模型不支持图片，任务会报告接口错误，不会偷偷丢掉图片当成已读取。DeepSeek与Claude不直接接收原图，因此图片判断与视觉核验仍有模型误判风险。

TXT、Markdown、代码和常见文本数据直接提取；PDF最多前20页，DOCX提取正文与表格，XLSX提取各工作表前100行和30列。每个附件最多16000字符，总计最多48000字符，后续执行与核验还会按既有上下文策略截断。只提供了部分资料时会标注；不支持的类型或无法解析的附件会明确说明，不能据此宣称已阅读全部文件。

附件是在你点击发送后随任务提供给所配置的模型服务；添加和移除本身只写本机。发送的图片编码不另存入检查点，恢复时从本机附件重新构建请求；现有目标、回答和工具记录可能仍保留附件提取出的内容。附件与聊天属于私人资料，不应随公开源码上传。
