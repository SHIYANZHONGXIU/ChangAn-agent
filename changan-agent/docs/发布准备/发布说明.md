# GitHub 与知乎发布准备

GitHub 用于保存源码、使用说明与版本；知乎发布项目介绍文章，再链接到 GitHub。不要把整个日常使用的 Agent 文件夹直接拖到网上。

## 目前准备的内容

- `知乎文章草稿.md`：开发分享文章，可编辑后复制进知乎文章编辑器；发布前补 GitHub 仓库链接。
- `outputs/publication/2026-11-01/`：独立源码目录、可上传压缩包及扫描清单。这里不会包含本地密钥、聊天、用户项目、日志和旧版归档。

源码包用于上传；不要把包外的扫描报告和个人工作目录一起上传。解压后使用源码文件夹中的文件创建仓库，ZIP 本身不应作为唯一源码提交。

## GitHub

1. 登录 GitHub，创建仓库，建议名称 `changan-agent`。
2. 选择公开或私有。公开后，任何人都可能下载代码。
3. 上传准备好的源码目录内容，保留目录结构，尤其是 `tests`、`scripts` 和 `docs`。
4. 初次发布可填写说明：“长安：支持多模型协作、工具执行和任务恢复的 Windows 桌面 Agent”。
5. 仓库没有许可证时，不代表已经授予他人自由修改、再发布的权利。若希望正式开源，可在确认后添加 MIT 等许可证。

## 知乎

1. 登录知乎，进入“写文章”。
2. 将草稿复制到编辑器，检查小标题、代码与段落。
3. 补上 GitHub 仓库链接。截图应使用演示聊天，避开密钥、私人文件路径和其他软件画面。
4. 按平台实际要求选择话题，并如实说明 AI 辅助开发，再预览发布。

## 需要你提供的内容

GitHub 用户名或目标仓库链接、仓库公开/私有选择，以及最终文章内容确认。登录和验证码在官网完成，不要在聊天中发送密码或访问令牌。
