## 本轮改动与验证

`experiments/memory/stress.py` 新增离线存储压力入口，拒绝覆盖已有实验数据库；结果保存有效协议、代码副本和哈希。`experiments/lora/run.py` 增加训练种子选择，并把实际生效配置保存为结果目录的 `protocol.json`。普通Python缺少训练依赖的一次失败记录保留在 `outputs/experiments/2026-11-02_105941-lora-seed43/`；改用既有 `.venv-lora` 后，2步冒烟和后续三次训练完成。

`experiments/lora/aggregate.py` 检查完成状态、种子、协议、数据/代码哈希及指标有效范围，拒绝不一致结果；至少3个种子，且每个种子的LoRA及混合条件都满足能力保留门槛，才可能判为值得继续研究。它只汇总报告，不会加载适配器或改变桌面设置。默认使用带时间的报告名，已有结果不会被覆盖。

最终 [本地回归报告](../outputs/verification/2026-11-02/checks.json) 为113项通过，0失败、0错误、0跳过。包含缺失检索失败记录、实验数据保护、混合协议拒绝、非法指标拒绝和退化拦截等回归。没有新增依赖，也没有修改日常聊天的数据格式。
