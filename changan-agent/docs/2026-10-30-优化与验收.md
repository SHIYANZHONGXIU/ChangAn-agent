# 长安：2026-10-30 优化与验收

本次已直接修改桌面程序、执行引擎、文件存储、网络工具和启动入口。用户原有配置与聊天继续保留。目标是让任务有真实执行、可追溯记录、可取消请求和可恢复进度，不将模型声称“完成”当成执行证据。

## 已落实的行为

| 使用场景 | 当前行为 |
| --- | --- |
| 多模型协作 | GPT 分析、DeepSeek 逐步执行；有 Claude 密钥时优先 Claude 审核，请求不可用则本任务改用 GPT；取消或预算错误不触发降级 |
| 真实工具执行 | DeepSeek 根据真实工具结果继续下一步，支持读写项目文件、命令、网页、浏览器及办公文档工具 |
| 审批 | ask for approve 需要实际确认；未提供审批通道时拒绝修改和命令；full access 保留项目文件边界和部分危险命令检查 |
| 中断与恢复 | 各阶段保存检查点；恢复审核不重跑已完成工具；结果不确定的副作用需再次确认；增加轮次可继续未通过任务 |
| 网络异常 | 有限重试、退避、总超时；拒绝截断流和空回复；不兼容的思考参数自动移除重试；停止可终止模型和网页工具请求进程 |
| 聊天保存 | 独立聊天目录、原子替换和上一版本备份；改名、移动保留附件和运行记录；最终答案先完整保存，再播放显示动画 |
| 主聊天与详情 | 主对话保留回答；目标、工具、审核、流式输出进入运行详情；可复制回答和代码，代码保留缩进及空行 |
| 多项任务 | 单并发持久队列；不重复用户消息，后面提交的请求不混入前一个任务的历史上下文 |
| 文件版本 | 按完整相对路径匹配历史版本，支持差异和恢复；恢复前备份当前文件，避免拿错其他目录中的同名文件 |
| 安全与诊断 | Windows DPAPI 保存密钥；滚动脱敏日志；单实例锁；HTTP 固定经过检查的公网 IP，重定向逐次检查 |
| 用量与预算 | 输入、输出分别计价；任务请求和重试前检查预算；缺失用量标为估算，未配置价格不显示为零成本 |

额外修复了后台线程直接操作界面、运行记录编号不一致、聊天改名丢目录、代码块窗口错误、窗口关闭时定时器重复删除，以及工具执行后格式错误丢失操作证据等问题。

## 使用与回退

双击根目录“启动桌面版.bat”。安装、测试与启动入口都优先使用项目中的 `.venv`，没有时使用系统 Python。停止当前运行后，重新打开窗口即可加载更新。

任务中断可点击“恢复中断任务”。达到原轮次上限的任务，先增大“最大核对轮次”再恢复。停止会清空等待队列；关闭窗口则保留尚未开始的队列。

改动前源码位于 `archive/2026-10-30-before-hardening/`。若要回退，应先关闭程序并备份现有工作区、加密配置及项目 `.changan`，按需恢复源码；不要用旧配置覆盖新聊天索引。

## 尚存边界

- 本轮真实 API 请求为零，未验证用户端点的余额、当前模型别名和实际聊天响应。模拟测试通过不能替代真实服务联调；Claude 目前需要 OpenAI 兼容接口，不支持原生 Anthropic Messages。
- full access 属于应用权限策略，不能提供操作系统级隔离；浏览器也不是独立网络沙箱。
- 基础验证器检查工具失败和新写入 Python、JSON、CSV 的格式，不能证明业务逻辑或外部事实正确。读取原本存在的错误代码不会被误判为本次写入失败。
- 预算是依据用户价格的估算，已发出的请求仍可能超限；失败请求的实际计费由服务商决定。
- 暂不提供签名安装包、多用户服务、完整办公编辑器。办公解析等同步短操作仍需等待返回；跨文件、跨磁盘迁移不具备数据库式整体事务保证，重要项目仍应定期备份。

这是经过本机回归的可用桌面 Agent，不是对所有环境和任务的无故障保证。
