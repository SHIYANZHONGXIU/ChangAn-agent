# 长安的文件放在哪里

现在默认把聊天、产物、设置和运行记录集中到 `Agent/data/`，应用源码继续放在 Agent 根目录。双击“启动桌面版.bat”即可使用。

| 文件夹 | 用途 | 是否可以直接删除 |
| --- | --- | --- |
| `data/config/` | API 地址、模型选择、本机加密密钥及上一版配置 | 保留，删除后需要重新配置 |
| `data/memory/` | 已确认记忆、待确认候选与已处理消息指纹 | 保留，删除后记忆与去重状态丢失 |
| `data/projects/` | 按项目、聊天、运行整理的记录和产物 | 保留，不能当缓存清理 |
| `data/workspace.json` | 项目与聊天索引、排队任务 | 保留，不能用删除索引来修复问题 |
| `data/logs/` | 诊断日志，应用自动滚动保留 | 退出应用后可清理旧日志 |
| `data/migrations/` | 旧数据迁移记录 | 建议保留用于定位路径 |
| `docs/` | 使用、实施、发布说明 | 按需保留 |
| `tests/`、`scripts/` | 本地测试和检查工具 | 开发维护需要 |
| `experiments/` | 虚构记忆评测、LoRA源码与固定协议 | 开发研究需要，不含真实聊天 |
| `outputs/experiments/` | 真实API实验记录、LoRA适配器、评分与失败报告 | 不影响聊天；需要复查或回滚实验时保留 |
| `.venv-lora/` | 可选训练环境；本机复用既有CUDA运行库 | 不影响桌面聊天；删后需重新准备才能训练 |
| `outputs/verification/` | 每次测试的结果 | 不影响聊天，按需保留 |
| `outputs/maintenance/` | 整理清单与实际启动检查 | 建议保留用于核对 |
| `outputs/publication/` | GitHub、知乎发布材料和独立仓库副本 | 保留，可能含未推送的 Git 状态 |
| `archive/` | 历史版本与改动前的完整回退包 | 确认新版长期正常后再决定是否清理 |
| `__pycache__/`、`*.pyc` | Python 自动生成的缓存 | 可清理，运行后会再生成 |

每个项目使用稳定编号，名称和外部工作目录记录在 `project.json`。聊天目录采用“创建时间-聊天编号-聊天名称”；聊天改名、跨项目移动时，目录和其中的运行记录、产物同步移动。创建时间较早的聊天如果原记录只有分钟，目录时间也只精确到分钟，不补造时间。

```text
data/projects/项目编号/
  project.json
  .forget-intents/                    遗忘操作的恢复标记，成功完成后自动清理
  workspace/                         未绑定外部目录的项目工作文件
  chats/创建时间-聊天编号-名称/
    chat.json                        完整消息与草稿
    chat.json.bak                     上一版备份
    attachments/                     主动添加的文件与粘贴图片快照
    runs/时间-运行编号/
      run.json                       状态与运行时间
      checkpoint.json                恢复进度
      result.json                    完整结果
      events.jsonl                   详细过程
      artifacts/
        reports/answer.md            最终回答
        code/                        代码副本
        data/                        数据副本
        documents/                   办公文档副本
        images/                      图片副本
        other/                       其他副本
        index.json                   来源、时间、大小和校验值
  history/
    artifacts/类型/                  旧版项目产物
    unindexed-chats/                  原列表未引用的历史聊天及其任务
    runs/                            无法确定聊天归属的旧任务
    migration-backups/               迁移前的上一版聊天备份
```

聊天顶部“文件”打开产物浏览器，可以预览文本，并点击“打开本聊天文件夹”。文件工具、Excel 修改、浏览器截图与下载的副本按类型归档；同名文件保留原子目录，不同内容采用不同哈希后缀。实际项目代码保持原路径，方便使用编辑器、Git 和终端；命令生成的任意文件保留在实际工作区，暂不自动扫描整个项目来复制。

如果选择了外部项目文件夹，`workspace/` 不再承载其实际代码。聊天和归档副本仍保存到 Agent 内，外部项目中已有 `.changan` 和旧记录会先复制保留，不自动删除外部目录。所有聊天、任务索引和长期记忆都属于私人数据，`data/` 已加入 Git 忽略规则。

需要整体备份时，先正常退出长安，再复制 `data/`；外部项目的实际文件需要单独备份。“彻底忘记来源聊天”会删除该聊天目录及其运行、附件和备份，无法从本机恢复；不会删除外部项目代码、已经导出的副本或服务商已收到的请求。恢复到其他 Windows 用户时，DPAPI 密钥可能无法解密，需要重新填写。`archive/2026-11-02-before-storage/源码与数据回退.zip` 包含本次整理前的源码与私人数据，仅用于本机回退，不作为公开源码包上传。

如果“彻底忘记”过程中软件意外退出，`.forget-intents/` 中的记录用于下次启动继续完成清理；不要手动移除仍在处理的标记。完成后长安会自动删除该目录。

如果使用 `CHANGAN_DATA_DIR`，以上 `data/` 都指向指定的数据根目录。不要同时启动不同版本来写同一份数据。
