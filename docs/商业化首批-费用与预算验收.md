# 商业化首批：费用、预算与恢复验收

日期：2026-11-02。本批已修改长安桌面程序、模型请求入口及相关实验入口。验证使用本机模拟服务和临时数据，没有调用真实收费 API，没有启动训练，也没有改写用户的实际配置、密钥或聊天。

## 使用方式

退出后重新启动长安，在“设置与模型 → 运行”配置价格和预算。输入价、输出价的单位都是每千 token；若服务商提供每百万 token 价格，请先除以 1000。选择同一计价币种 CNY 或 USD，再填写任务预算。价格依据所用服务的实际报价填写，程序不会根据模型名称猜价格。

启用金额预算时，所有已配置模型都需要完整的输入价、输出价和统一币种，包括作为备用审核的 Claude。价格为 0 或留空表示未知，不表示免费。未启用金额预算仍可使用模型，但费用信息不完整时会显示“费用未知”。未实际请求的模型不影响本次费用汇总。

单次输出上限默认 4096 token，可在下拉框选择 1024、2048、4096、8192、16384、32768。长代码或长报告可以适当提高，但会增加请求前预留金额。各阶段指定的输出额度也不能突破此上限；服务不接受上限参数时会报告失败，不会静默删除上限。明确因长度上限或内容过滤而结束的回答不会自动重复同一请求。

预算不足时，界面显示“预算已暂停，可调整后恢复”，阻止新请求并保留进度。核对记录、调整设置后，使用原任务的恢复入口继续。旧任务若缺少历史价格或币种，不能靠补填当前价格伪造历史账单；应先核实记录，或明确接受风险后关闭该任务的本机金额预算。

## 本批完成的行为

- 每次请求和重试都先预留输入与最大输出费用；分析、执行、审核、Claude 转 GPT、自动记忆提取共用任务预算，不各自领取完整额度。
- 请求发送前保存用量状态，保存失败则不发送。返回、失败和取消后再次保存；保存失败会报错，磁盘持续故障仍需人工处理。
- 每次记录模型、时间、输入与输出单价、币种、预留量、状态、用量来源及估算金额。账本位于任务检查点的 `usage.*.request_log`，不在账本里重复保存正文或密钥；检查点的其他字段仍包含任务上下文。
- 服务返回合法 usage 时替换该次预留；缺失或异常 usage 时保留有效回答，按预留量估算。失败、断线和取消可能已经计费，因此保留相应估算，而非自动算作免费。
- 恢复时把未完成请求标记为不确定，保留原金额并补记估算 token；反复恢复不会重复累计。调整价格不重算已发生的请求，移除 Claude 配置也不会抹掉它的历史费用。
- 任一实际使用模型缺价、缺币种或币种混用时，汇总显示“费用未知”；有未确认请求时显示预留提示。成功和失败消息均使用同一汇总规则。
- 首轮记忆评测与补测入口增加逐请求 token 预留和持久化；第二轮评测保留既有的独立 token 门控（单次请求不自动重试），补传计价币种。未重新运行真实评测或改写历史结果。

## 回退与限制

修改前源码快照：`archive/2026-11-02-before-budget-155125/source.zip`。需要回退时先关闭软件，另存当前源码，再按压缩包内的相对路径恢复对应源码；不要覆盖 `data`、用户配置、聊天、记忆或产物。该快照只用于源码回退，不会撤销已经发送的请求，也不能冲销服务账单。

本机预算是估算控制，不是服务商账单硬限额。当前输入预留采用序列化 UTF-8 请求字节数加 1024，输出按配置上限预留；图片、隐藏上下文、特殊思考计费、供应商异常计费或不遵守输出上限时，实际账单可能不同。请同时使用服务商账户额度限制。价格变化也需要用户自行维护。

保守预留可能使任务较早暂停；“含未确认请求预留”不表示该金额已由服务商确认扣费。本批没有进行真实 API 价格/取消联调、此次新增设置的人工截图验收、干净电脑安装或商业发布。已有测试通过不等于所有线上故障都已覆盖。
