## 怎么使用

1. 若长安已打开，请先正常退出，再双击项目根目录的“启动桌面版.bat”。原配置和聊天格式沿用，不需要删除或重新创建工作区。
2. 模型设置位于左下角“设置与模型”，按 GPT、DeepSeek、Claude、运行分组；点击输入框下方模型名称会直接打开 DeepSeek 页。运行中的任务沿用启动时的设置，修改用于后续任务。
3. 用户消息右下角有“记为记忆”。点击后检查内容、填写标题，选择“当前项目”或“通用”以及事实、偏好、项目状态类型，再点“确认保存”。引用和猜测需要自行核对，不自动写入。
4. 左下角“记忆”可新建、搜索、编辑、删除和查看来源。“通用”对所有项目可见，项目记忆按项目编号隔离；聊天移动后，来源项目的记忆保留原范围。
5. 新建聊天或重启后，相关记忆会作为参考数据进入分析、执行和核验。运行详情显示命中的条目标题。设置的“运行”页可以关闭记忆使用。
6. 上翻历史时停止跟随新消息；点击“最新消息”返回底部。代码可保留缩进复制，主聊天保留回答与简短用时，详细过程按需打开。

## 实现与边界

- 记忆数据库：`data/memory/memory.sqlite3`（11月2日目录整理后）。使用事务、明确来源和修订号；不覆盖同名记录，需要编辑原条目确认。没有将私人历史导入测试。
- 中文检索：中文相邻双字与英文关键词匹配，最多 6 条、内容和标题合计 5000 字符。偏好可以在无关键词命中时参与；同义词、模糊指代和大量记忆下的性能仍需后续评测。
- 每次模型阶段请求重新读取有效记忆，不把独立记忆数组保存进检查点。读取失败时继续普通聊天；损坏的记忆库保留原文件，界面提示不可用。
- 删除从当前数据库移除条目，安全删除模式减少数据库空闲页中的残留。但**不会删除原聊天、模型旧回答、既有运行记录或用户自行制作的备份**。这些内容仍可能在正常聊天历史或恢复结果中出现，本版不是彻底遗忘机制。
- 记忆库未加密。常见 API 密钥、令牌与私钥格式会被拒绝，不能把它当作完整敏感信息检测或密码管理器。模型文件工具也会拒绝直接读取记忆库，但命令工具仍不属于操作系统隔离。
- 记忆内容会随相关模型请求发送到用户配置的服务。数据库及附属文件已加入忽略规则，当前旧发布包没有自动更新，后续上传需重新生成并检查清单。
- 当前仍为单机个人应用；存储有用户和项目过滤字段，不代表已经实现多用户身份认证。
